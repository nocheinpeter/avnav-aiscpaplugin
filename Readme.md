AvNav AIS CPA plugin
====================
Draw AIS CPA on CPA using [AvNav](https://github.com/wellenvogel/avnav) plugin API (requires at least AvNav 20260104).

Based on [AvNav Testplugin](https://github.com/wellenvogel/avnav-testplugin/tree/master)

Build it<br>
`./setVersion.sh && ./build.sh`

Upload the zip at the Downloadpage/Tab Plugins.
